# dsh-turn-bookmarks

把右边的回合刻度变成可收藏的书签：**右键任意刻度**即可收藏/取消收藏，刻度变金黄色；左侧会出现一条只显示当前对话收藏的固定刻度条，顶部星标按钮打开**跨对话收藏面板**。

## 行为

- **右键右侧刻度**：收藏这一轮；再右键一次取消。右侧对应刻度变金色。
- **左侧收藏刻度**：独立于右侧 rail 的滚动，只显示**当前对话**的收藏轮次；点击直接跳到那一轮。
- **顶部星标**：显示全部对话的收藏总数；点击打开收藏面板。
- **收藏面板**：列出**所有对话**的收藏轮次，带会话标题、问题预览和轮次；点击会先打开对应会话，再跳到那一轮；点 × 删除。
- **跨对话**：面板不随当前对话切换而丢失其他会话的收藏；点击其他会话的收藏会通过 DSH 的会话导航打开它。
- **持久化**：保存在浏览器 localStorage 的全局收藏列表，刷新/重新打开 DSH 后仍在。
- **跳转**：目标轮次已加载时直接滚动；尚未加载时借用 DSH 自己的右侧刻度跳转，以保留历史加载逻辑。

## 安装

```text
file:<下载目录>\dsh-turn-bookmarks-0.2.0.tgz
```

或从源码目录：

```text
link:<repo>\packages\dsh-turn-bookmarks
```

安装后出现在 **设置 → 插件**，可随时启停。

## 数据与隐私

收藏只存在本机浏览器的 localStorage，使用一个全局收藏列表（按 `sessionId + 轮次` 去重）；不写会话日志、不上传。每条记录只保存截断的问题预览、会话标题、轮次和时间。

## 已知限制

- 依赖 DSH Web 当前刻度 rail 的 DOM（按钮的 `data-index` 和本地化 `aria-label`）；DSH 大改版后可能需要调整。
- 只有**已渲染**的右侧刻度能右键；被虚拟化掉的历史刻度需要先在右侧 rail 滚动到它。
- 收藏面板的问题预览在收藏时抓取；如果那一轮当时尚未加载，会显示“尚未加载”，点击后再加载跳转。
- 跨对话跳转依赖该会话仍然存在且可打开；已删除/归档的会话会无法跳转。
- 收藏是本机级、按浏览器 origin 存储的，不跨设备同步；DSH Web 端口变化会被浏览器视为不同 origin。
