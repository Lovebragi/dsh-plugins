# dsh-jump-to-question

回复太长时，回答结束后自动跳回**你发出这个问题的那条消息**，不用再往上翻好几页，也不用去点右边的刻度条。

## 行为

- 回合结束、回答已经完整渲染后，等约 **1.4 秒**；
- 如果这时你的问题已经被顶出视口上方，并且你还在回答末尾（距离底部 32px 以内），就直接跳到问题顶部；
- 如果你已经自己往上翻、不在底部，**不会**把你拽走，只在输入框下方显示一个「回到问题」按钮；
- 问题本来就没被顶出视口（短回复）时，不动作；
- 打开历史会话时不会自动跳，避免一进来就乱跑；
- 手动点击「回到问题」随时可用，平滑跳到本轮问题顶部；
- 尊重 `prefers-reduced-motion`：开启减少动态效果时用瞬时跳转。

## 实现方式

纯前端、只读 DOM：

- 用 `[data-chat-flow-kind="user"][data-chat-turn="N"]` 找到本轮用户提问；
- 用 `[data-turn-tail="N"]` 与 `[data-actions-reveal]` 判断回答已完成；
- 找最近的实际滚动容器（通常是 `[data-conversation-scroll]`），读取问题相对视口的位置；
- 滚动前检查自己是否还在底部，避免打断正在阅读的人。

不访问网络，不写会话日志，不读写任何账户或余额数据。

## 安装

已经作为 bundle 安装到 `desktop` profile，可在 **设置 → 插件** 里启停。

从 tgz 安装：

```text
file:<下载目录>\dsh-jump-to-question-0.1.0.tgz
```

从源码目录安装：

```text
link:<repo>\packages\dsh-jump-to-question
```

## 可选调整

高级用法：在浏览器控制台设置全局覆盖（刷新页面后生效）：

```js
globalThis.__DSH_JUMP_TO_QUESTION__ = {
  autoJump: true,       // false = 只显示按钮，不自动跳
  delayMs: 1400,        // 回答结束后等多久再跳
  bottomThresholdPx: 32 // 距离底部多少像素内算“还在底部”
};
```

## 已知限制

- 依赖 DSH Web 当前会话 DOM 的 `data-chat-*` 标记；DSH 大版本改版后可能需要同步更新。
- 只对已经完成、且产生了回答内容的回合生效；被中断且没有回答的回合不会自动跳（有部分回答后停止的回合仍可能触发）。
- 如果回答结束时你正停在中间阅读，会尊重当前位置，只给按钮。
